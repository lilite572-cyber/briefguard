# Как читать демо

Открой `http://127.0.0.1:8765/` при запущенном сервере из README.
Это просмотр сохранённого CPU-эксперимента: переключение примера не запускает
новый анализ и не вызывает платную модель.

1. Карточки сверху — весь тест при бюджете 8 кадров: uniform 34,90%, change
   43,62%, adaptive 41,54% обнаруженных нарушений. Это не accuracy по всем клипам.
2. Выбери пример 04. Нарушение занимает кадры 8–13. Adaptive выбирает кадр 12
   и обнаруживает запрещённый красный элемент. Uniform и change пропускают интервал.
3. Выбери пример 03 и метод Uniform. Метод попал в интервал, но проверяющий
   не распознал нарушение. Это отдельная причина ошибки, которую одной выборкой
   кадров не исправить.
4. Синие отметки — выбранные кадры, красные — находки проверяющего,
   жёлтый интервал — известная разметка генератора. Клик по кадру показывает его
   в проигрывателе. Ground truth скрывает только разметку на таймлайне и кадре;
   это объясняющий интерфейс, не слепая человеческая разметка.
5. `Violation missed` означает ошибку системы даже при `Checker output: Pass`.
   `Event sampled: No` указывает на пропуск при выборке; `Yes` вместе с пропуском
   указывает на ошибку проверяющего.

Один удачный пример adaptive не опровергает общий результат. Исходная гипотеза
не подтвердилась; разница adaptive − change равна −2,08 п.п. с интервалом
[−4,95; +0,65]. Для реальных видео и VLM это исследование выводов не даёт.

Оформление использует Tabler как визуальный референс:
https://github.com/tabler/tabler и https://preview.tabler.io/ (MIT).
Светлая палитра, компактные панели и таблицы реализованы собственным CSS;
код, логотип, шрифты и библиотеки Tabler не включены в проект.
