От требований к проверяемым кадрам

Сформулируйте визуальные требования и подготовьте локальный запуск. Получите выбранные кадры, их временные отметки и отчёт для проверки.

Эта страница не отправляет файлы в сеть и не запускает модель. Подготовка выполняется отдельной командой на вашем компьютере. До получения настоящего ответа модели результат проверки отсутствует.

1. Укажите исходные данные

Путь используется только в команде. Браузер не имеет доступа к указанному пути. MP4/MOV этим процессом не декодируются.

Укажите реальную постоянную частоту исходника. Переменную частоту нельзя молча заменять постоянной.

Предварительный просмотр GIF на этом устройстве

Это только просмотр: он не запускает декодер BriefGuard и не подтверждает требования. Полный путь для команды всё равно нужно указать выше.

2. Запишите требования

Формулируйте то, что можно увидеть на кадре. «Ролик должен быть хорошим» не задаёт проверяемого критерия. Проверка отдельных кадров не подтверждает соблюдение требования между ними.

Скачайте файл и поместите его по этому пути относительно корня репозитория либо укажите абсолютный путь.

3. Подготовьте кадры и отчёт

Используйте новую папку для нового запуска. Не перезаписывайте результаты исследования. Папки results/private* не публикуются в Git.



Запустите из корня репозитория в Python-окружении с установленными зависимостями. Команда не обращается к API. Затем откройте report.html внутри папки результатов: там находятся выбранные кадры и их отметки времени.




4. Отдельный платный запуск — только после согласования
Провайдер: OpenAI. Модель: gpt-4.1-mini-2025-04-14. Общий плановый лимит: $0,50; максимум 36 попыток с повторами. Пока разрешение на эти расходы не получено, оставайтесь на шаге подготовки.
Копирование команды не является разрешением на расходы. Эта страница ничего не запускает. После отдельного согласования ключ задаётся через OPENAI_API_KEY в окружении процесса, вне чата и репозитория.
Все подготовки используют общий журнал results/private-workbench-api. Не удаляйте его и не создавайте новую копию репозитория для обхода лимита. Резерв $0,01 за попытку — локальное ограничение, не гарантия счёта провайдера. После выполнения заново откройте report.html. Проверка выбранных кадров не подтверждает весь ролик.


5. Альтернатива: импорт готового ответа
Подготовленная папка содержит request.json. Если запрос уже выполнен отдельно, можно импортировать сохранённый ответ вместо повторной оплаты. Эта страница не выполняет вызов. Не вставляйте API-ключи в файлы проекта или в эту страницу.




Импорт проверяет структуру и ссылки на кадры и требования. Происхождение ответа от провайдера и связь с этим запросом не аутентифицированы. Это не проверка правдивости вывода модели и не человеческая разметка. После импорта заново откройте report.html и сопоставьте доказательства с кадрами. Без ответа не следует считать ролик прошедшим проверку.


Эксперимент на синтетических данных и проверка нового ролика — разные задачи. Этот интерфейс не меняет исходный протокол, алгоритмы или опубликованные результаты.
